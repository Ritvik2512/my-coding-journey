# Scratchpad

Welcome.

This repository is a collection of code I’ve written while learning and experimenting with programming.

It started off mostly with C/C++, but my focus is gradually shifting toward Python, especially in the context of AI/ML. You’ll find a mix of fundamentals, small experiments, and projects as I build my understanding over time.

This isn’t meant to be perfectly structured — it’s a working archive of progress, iteration, and exploration.

The goal is simple: keep building and keep improving.

## What's Inside

| Folder | Description | Tech |
|--------|-------------|------|
| `c-programs` | Learning exercises from early C programming | C |
| `gpa-calculator` | Simple React app for GPA calculation | React, JavaScript |
| `Deepfake-Analyzer` | Deep learning model for deepfake detection (guided workshop) | Python, TensorFlow |
| `house-price-predictor` | ML model predicting house prices | Python, scikit-learn |
| `spam-sms-classifier` | Text classification model for SMS spam detection | Python, scikit-learn |
| `devops-log-analyzer` | Multi-agent AI pipeline that analyzes logs and generates remediation plans, runs fully locally via Ollama | Python, CrewAI, Ollama |
